# The <span class="math">$&#92;displaystyle k$</span>-th maximum of a group continuous functions <span class="math">$&#92;displaystyle f&#95;{1},f&#95;{2},&#92;dots,f&#95;{n}$</span> is continuous for all <span class="math">$&#92;displaystyle i &#92;in I:=&#92;left&#92;{ 1,2,&#92;dots,n &#92;right&#92;}$</span>.

Step 1: The maximum function <span class="math">$&#92;displaystyle &#92;mathop{&#92;max}&#92;left&#92;{ f,g &#92;right&#92;}=g+ &#92;frac{f-g+|f-g|}{2}$</span> is continuous since absolute value operator preserves continuity of function. By induction, the maximum function <span class="math">$&#92;displaystyle &#92;mathop{&#92;max}&#92;limits&#95;{i &#92;in I}&#92;left&#92;{ f&#95;{i} &#92;right&#92;}$</span> is continuous for finitely many continuous functions <span class="math">$&#92;displaystyle (f&#95;{i})&#95;{i &#92;in I}$</span>

Step 2: The minimum function <span class="math">$&#92;displaystyle &#92;mathop{&#92;min}&#92;limits&#95;{i &#92;in I}&#92;left&#92;{ f&#95;{i} &#92;right&#92;}=-&#92;mathop{&#92;max}&#92;limits&#95;{i &#92;in I}&#92;left&#92;{ -f&#95;{i} &#92;right&#92;}$</span> is continuous since maximum operator preserves continuity.

Step 3: For all <span class="math">$&#92;displaystyle k &#92;in I$</span>, the <span class="math">$&#92;displaystyle k$</span>-th maximum function <span class="math">$&#92;displaystyle &#92;mathop{&#92;max&#92;left( k &#92;right)}&#92;limits&#95;{i &#92;in I}&#92;left&#92;{ f&#95;{i} &#92;right&#92;}=&#92;mathop{&#92;min}&#92;limits&#95;{I' &#92;subset I, |I'|=n-k+1}&#92;left&#92;{ &#92;mathop{&#92;max}&#92;limits&#95;{i &#92;in I'}&#92;left&#92;{ f&#95;{i} &#92;right&#92;} &#92;right&#92;}$</span> is continuous since both minimum and maximum operators preserve continuity of functions.
