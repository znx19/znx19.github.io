## Lexicographic preference is not continuous, is convex, and is monotonic
The following explanation will be based on 2-good case, and it could be easily extended to n-good case.
Fix a consumption bundle <span class="math">$&#92;displaystyle x=&#92;left( x&#95;{1},x&#95;{2} &#92;right)>0$</span>, the upper contour set of <span class="math">$&#92;displaystyle x$</span> is <span class="math">$&#92;displaystyle U&#92;left( x &#92;right)=&#92;left&#92;{ y&#92;in &#92;mathbb{R}&#95;{+}^{2}: y&#95;{1}>x&#95;{1} &#92;right&#92;}&#92;cup&#92;left&#92;{ y&#92;in &#92;mathbb{R}&#95;{+}^{2}: y&#95;{1}=x&#95;{1}&#92;cap y&#95;{2}&#92;geq x&#95;{2} &#92;right&#92;}$</span>. Notice that <span class="math">$&#92;displaystyle U&#92;left( x &#92;right)$</span> is not closed. Consider a sequence of points <span class="math">$&#92;displaystyle x^{n}=&#92;left( x&#95;{1}+&#92;frac{1}{n}, &#92;frac{1}{2}x&#95;{2} &#92;right)$</span>. For all <span class="math">$&#92;displaystyle n&#92;geq 1$</span>, <span class="math">$&#92;displaystyle x^{n}&#92;in U&#92;left( x &#92;right)$</span> since <span class="math">$&#92;displaystyle x^{n}&#95;{1}>x&#95;{1}$</span>. But <span class="math">$&#92;displaystyle &#92;lim&#95;{ n &#92;to &#92;infty }x^{n}=&#92;left( x&#95;{1},&#92;frac{1}{2}x&#95;{2} &#92;right) &#92;not&#92;in U&#92;left( x &#92;right)$</span> since <span class="math">$&#92;displaystyle x&#95;{1}=x&#95;{1}&#92;cap &#92;frac{1}{2}x&#95;{2}<x&#95;{2}$</span>. Thus, the lexicographic preference is not continuous.

For any consumption bundle <span class="math">$&#92;displaystyle x=&#92;left( x&#95;{1},x&#95;{2} &#92;right)$</span>, if there are 2 alternative bundles <span class="math">$&#92;displaystyle y,y'$</span> which are at least as good as <span class="math">$&#92;displaystyle x$</span>: <span class="math">$&#92;displaystyle y,y'&#92;in U&#92;left( x &#92;right)$</span>, then any convex combination <span class="math">$&#92;displaystyle y&#95;{&#92;alpha}=&#92;alpha y+&#92;left( 1-&#92;alpha &#92;right)y'$</span> is also at least as good as <span class="math">$&#92;displaystyle x$</span>: <span class="math">$&#92;displaystyle y&#95;{&#92;alpha}&#92;in U&#92;left( x &#92;right)$</span>. Thus, the lexicographic preference is convex.

For any consumption bundle <span class="math">$&#92;displaystyle x=&#92;left( x&#95;{1},x&#95;{2} &#92;right)$</span>, and any positive vector <span class="math">$&#92;displaystyle &#92;Delta x=&#92;left( &#92;Delta x&#95;{1},&#92;Delta x&#95;{2} &#92;right)>0$</span>, the new bundle <span class="math">$&#92;displaystyle x+&#92;Delta x$</span> is preferred to <span class="math">$&#92;displaystyle x$</span> since <span class="math">$&#92;displaystyle&#92;left( x+&#92;Delta x &#92;right)&#95;{1}>x&#95;{1}$</span>. Thus, <span class="math">$&#92;displaystyle x+&#92;Delta x &#92;in U&#92;left( x &#92;right)$</span>, implying that the lexicographic preference is monotonic. To be more specific, it is strictly monotonic.

## In the 2-agent 2-good case, the Pareto set is either the whole Edgeworth box or the right and bottom segment, with each single point as the Pareto equivalent class.

## In the n-agent m-good case, construct the Pareto set in the following steps:

### Step 1: Collect the first column of matrix <span class="math">$&#92;displaystyle A$</span>: <span class="math">$&#92;displaystyle A&#95;{1}:=&#92;left( a&#95;{1}^{i} &#92;right)&#95;{i &#92;leq n}$</span>.
Pick a good index <span class="math">$&#92;displaystyle gi&#95;{1}$</span> from this collection <span class="math">$&#92;displaystyle A&#95;{1}$</span>, find all agent index <span class="math">$&#92;displaystyle B&#95;{gi}^{1}$</span> whose 1st priority is good <span class="math">$&#92;displaystyle gi$</span>: <span class="math">$&#92;displaystyle B&#95;{gi}^{1}=&#92;left&#92;{ ai&#92;leq n: a&#95;{1}^{ai}=gi &#92;right&#92;}$</span>. 
Pick a distribution on <span class="math">$&#92;displaystyle B&#95;{gi}^{1}$</span>, such that the total consumption of these agents in <span class="math">$&#92;displaystyle B&#95;{gi}^{1}$</span> on good <span class="math">$&#92;displaystyle gi$</span> is equal to the total endowment of good <span class="math">$&#92;displaystyle gi$</span>: <span class="math">$&#92;displaystyle &#92;sum&#95;{i &#92;in B&#95;{gi}^{1}}x&#95;{gi}^{i}=M&#95;{gi}$</span>
Pick another feasible distribution on the other agents <span class="math">$&#92;displaystyle N-B&#95;{gi}^{1}$</span> and other goods included in <span class="math">$&#92;displaystyle A&#95;{1}$</span>: <span class="math">$&#92;displaystyle A&#95;{1}-&#92;left&#92;{ gi &#92;right&#92;}$</span>, such that the total consumption of these agents  <span class="math">$&#92;displaystyle N-B&#95;{gi}^{1}$</span> should not exceed the total endowment of other good <span class="math">$&#92;displaystyle A&#95;{1}-&#92;left&#92;{ gi &#92;right&#92;}$</span>.
Finally, we get a vector on the remaining endowment: <span class="math">$&#92;displaystyle M^{1}&#92;leq M$</span>, with the remaining endowment of good <span class="math">$&#92;displaystyle gi$</span> is 0: <span class="math">$&#92;displaystyle M^{1}&#95;{gi}=0$</span>.
### Step 2: Collect the second column of matrix <span class="math">$&#92;displaystyle A$</span>: <span class="math">$&#92;displaystyle A&#95;{2}:=&#92;left( a&#95;{2}^{i} &#92;right)&#95;{i &#92;leq n}$</span>.
Pick a different good index in step 1 <span class="math">$&#92;displaystyle gi&#95;{2} &#92;not=gi&#95;{1}$</span> from this collection <span class="math">$&#92;displaystyle A&#95;{2}$</span>, find all agent index <span class="math">$&#92;displaystyle B&#95;{gi&#95;{2}}^{2}$</span> whose 2nd priority is good <span class="math">$&#92;displaystyle gi&#95;{2}$</span>: <span class="math">$&#92;displaystyle B&#95;{gi&#95;{2}}^{2}=&#92;left&#92;{ ai&#92;leq n: a&#95;{2}^{ai}=gi&#95;{2} &#92;right&#92;}$</span>. 
Pick a distribution on <span class="math">$&#92;displaystyle B&#95;{gi&#95;{2}}^{2}$</span>, such that the total consumption of these agents in <span class="math">$&#92;displaystyle B&#95;{gi&#95;{2}}^{2}$</span> on good <span class="math">$&#92;displaystyle gi&#95;{2}$</span> is equal to the total available endowment of good <span class="math">$&#92;displaystyle gi&#95;{2}$</span>: <span class="math">$&#92;displaystyle &#92;sum&#95;{i &#92;in B&#95;{gi&#95;{2}}^{2}}x&#95;{gi&#95;{2}}^{i}=M&#95;{gi&#95;{2}}^{1}$</span>
Pick another feasible distribution on the other agents <span class="math">$&#92;displaystyle N-B&#95;{gi&#95;{2}}^{2}$</span> and other goods included in <span class="math">$&#92;displaystyle A&#95;{2}$</span>: <span class="math">$&#92;displaystyle A&#95;{2}-&#92;left&#92;{ gi&#95;{2} &#92;right&#92;}$</span>, such that the total consumption of these agents  <span class="math">$&#92;displaystyle N-B&#95;{gi&#95;{2}}^{2}$</span> should not exceed the total endowment of other good <span class="math">$&#92;displaystyle A&#95;{2}-&#92;left&#92;{ gi&#95;{2} &#92;right&#92;}$</span>.
Finally, we get a vector on the remaining endowment: <span class="math">$&#92;displaystyle M^{2}&#92;leq M^{1}$</span>, with the remaining endowment of good <span class="math">$&#92;displaystyle gi&#95;{1}$</span> and good <span class="math">$&#92;displaystyle gi&#95;{2}$</span> is 0: <span class="math">$&#92;displaystyle M^{2}&#95;{gi&#95;{1}}=M^{2}&#95;{gi&#95;{2}}=0$</span>.
### Step 3: Repeat Step 2 until all m good is totally distributed to n agents. We get one Pareto efficient allocation.
### Step 4: Repeat Step 1 to Step 3, exhaust all the possibilities for each "Pick" operation in each step. Finally, we could get a set of all Pareto efficient allocations.

It is easy to show such a set generated from above steps is exactly the Pareto set.
