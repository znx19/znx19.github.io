## Lexicographic preference is not continuous, is convex, and is monotonic
The following explanation will be based on 2-good case, and it could be easily extended to n-good case.
Fix a consumption bundle $\displaystyle x=\left( x_{1},x_{2} \right)>0$, the upper contour set of $\displaystyle x$ is $\displaystyle U\left( x \right)=\left\{ y\in \mathbb{R}_{+}^{2}: y_{1}>x_{1} \right\}\cup\left\{ y\in \mathbb{R}_{+}^{2}: y_{1}=x_{1}\cap y_{2}\geq x_{2} \right\}$. Notice that $\displaystyle U\left( x \right)$ is not closed. Consider a sequence of points $\displaystyle x^{n}=\left( x_{1}+\frac{1}{n}, \frac{1}{2}x_{2} \right)$. For all $\displaystyle n\geq 1$, $\displaystyle x^{n}\in U\left( x \right)$ since $\displaystyle x^{n}_{1}>x_{1}$. But $\displaystyle \lim_{ n \to \infty }x^{n}=\left( x_{1},\frac{1}{2}x_{2} \right) \not\in U\left( x \right)$ since $\displaystyle x_{1}=x_{1}\cap \frac{1}{2}x_{2}<x_{2}$. Thus, the lexicographic preference is not continuous.

For any consumption bundle $\displaystyle x=\left( x_{1},x_{2} \right)$, if there are 2 alternative bundles $\displaystyle y,y'$ which are at least as good as $\displaystyle x$: $\displaystyle y,y'\in U\left( x \right)$, then any convex combination $\displaystyle y_{\alpha}=\alpha y+\left( 1-\alpha \right)y'$ is also at least as good as $\displaystyle x$: $\displaystyle y_{\alpha}\in U\left( x \right)$. Thus, the lexicographic preference is convex.

|                                                   | $\displaystyle y_{1}> x_{1}$                                                     | $\displaystyle y_{1}=x_{1}\cap y_{2}\geq x_{2}$                                                                                                                      |
| ------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| $\displaystyle y_{1}'> x_{1}$                     | $\displaystyle y_{\alpha_{1}}=\alpha y_{1}+\left( 1-\alpha \right)y_{1}'> x_{1}$ | $\displaystyle y_{\alpha_{1}}=\alpha x_{1}+\left( 1-\alpha \right)y_{1}'> x_{1}$                                                                                     |
| $\displaystyle y_{1}'=x_{1}\cap y_{2}'\geq x_{2}$ | $\displaystyle y_{\alpha_{1}}=\alpha y_{1}+\left( 1-\alpha \right)x_{1}'> x_{1}$ | $\displaystyle y_{\alpha_{1}}=\alpha x_{1}+\left( 1-\alpha \right)x_{1}'= x_{1}$ $\displaystyle y_{\alpha_{2}}=\alpha y_{2}+\left( 1-\alpha \right)y_{2}'\geq x_{2}$ |

For any consumption bundle $\displaystyle x=\left( x_{1},x_{2} \right)$, and any positive vector $\displaystyle \Delta x=\left( \Delta x_{1},\Delta x_{2} \right)>0$, the new bundle $\displaystyle x+\Delta x$ is preferred to $\displaystyle x$ since $\displaystyle\left( x+\Delta x \right)_{1}>x_{1}$. Thus, $\displaystyle x+\Delta x \in U\left( x \right)$, implying that the lexicographic preference is monotonic. To be more specific, it is strictly monotonic.

## In the 2-agent 2-good case, the Pareto set is either the whole Edgeworth box or the right and bottom segment, with each single point as the Pareto equivalent class.

## In the n-agent m-good case, construct the Pareto set in the following steps:

### Step 0: Denote the order of priority for all n agents as a matrix $\displaystyle A$ as follows, where $\displaystyle a_{j}^{i}$ represent the index of good which is on the j-th priority of agent i.

| Agent \ Order | 1st Priority              | 2nd Priority              | ... | m-th Priority             |
| ------------- | ------------------------- | ------------------------- | --- | ------------------------- |
| 1             | $\displaystyle a_{1}^{1}$ | $\displaystyle a_{2}^{1}$ |     | $\displaystyle a_{m}^{1}$ |
| 2             | $\displaystyle a_{1}^{2}$ | $\displaystyle a_{2}^{2}$ |     | $\displaystyle a_{m}^{2}$ |
| ...           |                           |                           |     |                           |
| n             | $\displaystyle a_{1}^{n}$ | $\displaystyle a_{2}^{n}$ |     | $\displaystyle a_{m}^{n}$ |
### Step 1: Collect the first column of matrix $\displaystyle A$: $\displaystyle A_{1}:=\left( a_{1}^{i} \right)_{i \leq n}$.
Pick a good index $\displaystyle gi_{1}$ from this collection $\displaystyle A_{1}$, find all agent index $\displaystyle B_{gi}^{1}$ whose 1st priority is good $\displaystyle gi$: $\displaystyle B_{gi}^{1}=\left\{ ai\leq n: a_{1}^{ai}=gi \right\}$. 
Pick a distribution on $\displaystyle B_{gi}^{1}$, such that the total consumption of these agents in $\displaystyle B_{gi}^{1}$ on good $\displaystyle gi$ is equal to the total endowment of good $\displaystyle gi$: $\displaystyle \sum_{i \in B_{gi}^{1}}x_{gi}^{i}=M_{gi}$
Pick another feasible distribution on the other agents $\displaystyle N-B_{gi}^{1}$ and other goods included in $\displaystyle A_{1}$: $\displaystyle A_{1}-\left\{ gi \right\}$, such that the total consumption of these agents  $\displaystyle N-B_{gi}^{1}$ should not exceed the total endowment of other good $\displaystyle A_{1}-\left\{ gi \right\}$.
Finally, we get a vector on the remaining endowment: $\displaystyle M^{1}\leq M$, with the remaining endowment of good $\displaystyle gi$ is 0: $\displaystyle M^{1}_{gi}=0$.
### Step 2: Collect the second column of matrix $\displaystyle A$: $\displaystyle A_{2}:=\left( a_{2}^{i} \right)_{i \leq n}$.
Pick a different good index in step 1 $\displaystyle gi_{2} \not=gi_{1}$ from this collection $\displaystyle A_{2}$, find all agent index $\displaystyle B_{gi_{2}}^{2}$ whose 2nd priority is good $\displaystyle gi_{2}$: $\displaystyle B_{gi_{2}}^{2}=\left\{ ai\leq n: a_{2}^{ai}=gi_{2} \right\}$. 
Pick a distribution on $\displaystyle B_{gi_{2}}^{2}$, such that the total consumption of these agents in $\displaystyle B_{gi_{2}}^{2}$ on good $\displaystyle gi_{2}$ is equal to the total available endowment of good $\displaystyle gi_{2}$: $\displaystyle \sum_{i \in B_{gi_{2}}^{2}}x_{gi_{2}}^{i}=M_{gi_{2}}^{1}$
Pick another feasible distribution on the other agents $\displaystyle N-B_{gi_{2}}^{2}$ and other goods included in $\displaystyle A_{2}$: $\displaystyle A_{2}-\left\{ gi_{2} \right\}$, such that the total consumption of these agents  $\displaystyle N-B_{gi_{2}}^{2}$ should not exceed the total endowment of other good $\displaystyle A_{2}-\left\{ gi_{2} \right\}$.
Finally, we get a vector on the remaining endowment: $\displaystyle M^{2}\leq M^{1}$, with the remaining endowment of good $\displaystyle gi_{1}$ and good $\displaystyle gi_{2}$ is 0: $\displaystyle M^{2}_{gi_{1}}=M^{2}_{gi_{2}}=0$.
### Step 3: Repeat Step 2 until all m good is totally distributed to n agents. We get one Pareto efficient allocation.
### Step 4: Repeat Step 1 to Step 3, exhaust all the possibilities for each "Pick" operation in each step. Finally, we could get a set of all Pareto efficient allocations.

It is easy to show such a set generated from above steps is exactly the Pareto set.
