## In a fully allocation problem with infinitely divisible social endowment <span class="math">$&#92;displaystyle M &#92;in &#92;mathbb{R}&#95;{+}^{L}$</span> and strictly monotonic preferences, pairwise efficiency implies efficiency. If for all <span class="math">$&#92;displaystyle i,j &#92;in N$</span>, the pair <span class="math">$&#92;displaystyle (x&#95;{i},x&#95;{j})$</span> is an efficient way of distributing <span class="math">$&#92;displaystyle x&#95;{i}+x&#95;{j}$</span> among them, then <span class="math">$&#92;displaystyle x$</span> is an efficient allocation.

### If the social endowment <span class="math">$&#92;displaystyle M &#92;in &#92;mathbb{R}&#95;{+}^{1}$</span> is a single-dimensional good, then any full allocation <span class="math">$&#92;displaystyle x$</span> is Pareto efficient and the pairwise efficiency condition is redundant.

By the way of contradiction, suppose <span class="math">$&#92;displaystyle x$</span> is a pair-efficient allocation but is not efficient, i,e. there is another allocation <span class="math">$&#92;displaystyle y$</span> Pareto dominating <span class="math">$&#92;displaystyle x$</span>:
<div class="math">$$
&#92;begin{align}
&#92;forall i &#92;in N & &  u&#95;{i}&#92;left( y&#95;{i} &#92;right)&#92;geq u&#95;{i}&#92;left( x&#95;{i} &#92;right)  &  & &#92;implies y&#95;{i} &#92;geq x&#95;{i}&#92;&#92;
&#92;exists i^{&#92;star} &#92;in N &  & u&#95;{i^{&#92;star}}&#92;left( y&#95;{i^{&#92;star}} &#92;right) > u&#95;{i^{&#92;star}}&#92;left( x&#95;{i^{&#92;star}} &#92;right) &  & &#92;implies y&#95;{i^{&#92;star}} > x&#95;{i^{&#92;star}}&#92;&#92;
&#92;end{align}
$$</div>
where the right hand side is induced from monotonic preference on single-dimensional good. 
Take the summation on the inequalities, we have
<div class="math">$$
&#92;sum&#95;{i &#92;in N}y&#95;{i}>&#92;sum&#95;{i &#92;in N}x&#95;{i}=M
$$</div>
which is a contradiction with the feasible allocation.

### If the social endowment <span class="math">$&#92;displaystyle M &#92;in &#92;mathbb{R}&#95;{+}^{L>1}$</span> is a multiple-dimensional good, the pairwise efficiency does imply efficiency.

By the way of contradiction, suppose <span class="math">$&#92;displaystyle x$</span> is a pair-efficient allocation but is not efficient, i,e. there is another allocation <span class="math">$&#92;displaystyle y$</span> Pareto dominating <span class="math">$&#92;displaystyle x$</span>:
<div class="math">$$
&#92;begin{align}
&#92;forall i &#92;in N & &  u&#95;{i}&#92;left( y&#95;{i} &#92;right)&#92;geq u&#95;{i}&#92;left( x&#95;{i} &#92;right)  &#92;&#92;
&#92;exists i^{&#92;star} &#92;in N &  & u&#95;{i^{&#92;star}}&#92;left( y&#95;{i^{&#92;star}} &#92;right) > u&#95;{i^{&#92;star}}&#92;left( x&#95;{i^{&#92;star}} &#92;right) &#92;&#92;
&#92;end{align}
$$</div>
Take any pair <span class="math">$&#92;displaystyle (i,j) &#92;in N^{2}$</span>, claim:
1. If <span class="math">$&#92;displaystyle u&#95;{i}&#92;left( y&#95;{i} &#92;right)=u&#95;{i}&#92;left( x&#95;{i} &#92;right)  &#92;cap  u&#95;{j}&#92;left( y&#95;{j} &#92;right)=u&#95;{j}&#92;left( x&#95;{j} &#92;right)$</span>, then <span class="math">$&#92;displaystyle y&#95;{i}+y&#95;{j}&#92;geq x&#95;{i}+x&#95;{j}$</span>
	Otherwise, suppose <span class="math">$&#92;displaystyle y&#95;{i}+y&#95;{j}<x&#95;{i}+x&#95;{j}$</span>, we can easily construct an alternative allocation <span class="math">$&#92;displaystyle z =&#92;left( z&#95;{i}=y&#95;{i}, z&#95;{j}=y&#95;{j}+&#92;left( x&#95;{i}+x&#95;{j}-y&#95;{i}-y&#95;{j} &#92;right)>y&#95;{j} &#92;right)$</span>. By strict monotone of preference, <span class="math">$&#92;displaystyle z$</span> Pareto dominates <span class="math">$&#92;displaystyle x$</span> within the pair <span class="math">$&#92;displaystyle (i,j)$</span>, contradicting the pairwise efficiency.
2. If <span class="math">$&#92;displaystyle u&#95;{i}&#92;left( y&#95;{i} &#92;right)>u&#95;{i}&#92;left( x&#95;{i} &#92;right)  &#92;cap  u&#95;{j}&#92;left( y&#95;{j} &#92;right)=u&#95;{j}&#92;left( x&#95;{j} &#92;right)$</span>, then <span class="math">$&#92;displaystyle y&#95;{i}+y&#95;{j}> x&#95;{i}+x&#95;{j}$</span>
	Otherwise, suppose <span class="math">$&#92;displaystyle y&#95;{i}+y&#95;{j}&#92;leq x&#95;{i}+x&#95;{j}$</span>, we can easily construct an alternative allocation <span class="math">$&#92;displaystyle z =&#92;left( z&#95;{i}=y&#95;{i}+&#92;left( x&#95;{i}+x&#95;{j}-y&#95;{i}-y&#95;{j} &#92;right)&#92;geq y&#95;{i}, z&#95;{j}=y&#95;{j} &#92;right)$</span>. By monotone of preference, <span class="math">$&#92;displaystyle z$</span> Pareto dominates <span class="math">$&#92;displaystyle x$</span> within the pair <span class="math">$&#92;displaystyle (i,j)$</span>, contradicting the pairwise efficiency.

Take summation on all pairs <span class="math">$&#92;displaystyle (i,j)$</span>, we have
<div class="math">$$
&#92;sum&#95;{&#92;left( i,j &#92;right)}&#92;left( y&#95;{i}+y&#95;{j} &#92;right)=&#92;left( N-1 &#92;right)&#92;sum&#95;{i &#92;in N}y&#95;{i}>&#92;sum&#95;{&#92;left( i,j &#92;right)}&#92;left( x&#95;{i}+x&#95;{j} &#92;right)=&#92;left( N-1 &#92;right)&#92;sum&#95;{i &#92;in N}x&#95;{i}=&#92;left( N-1 &#92;right)M
$$</div>
which is a contradiction with the feasible allocation.

## In an object allocation problem, leave-one-out efficiency does not imply efficiency. If for all <span class="math">$&#92;displaystyle i &#92;in N$</span>, the allocation <span class="math">$&#92;displaystyle x&#95;{-i}$</span> is efficient for the problem with agent <span class="math">$&#92;displaystyle N-&#92;left&#92;{ i &#92;right&#92;}$</span> and social endowment <span class="math">$&#92;displaystyle &#92;cap&#95;{j &#92;neq i}x&#95;{j}$</span>, then <span class="math">$&#92;displaystyle x$</span> is not necessarily an efficient allocation.
