## Manipulation game: 
Set of agent <span class="math">$&#92;displaystyle i &#92;in &#92;{ 1, 2 &#92;}$</span> with true preference <span class="math">$&#92;displaystyle u&#95;{i}=x&#95;{1}^{a&#95;{i}}x&#95;{2}^{1-a&#95;{1}}$</span>.
Set of strategies <span class="math">$&#92;displaystyle &#92;beta&#95;{i} &#92;in &#92;mathcal{R}$</span> is the collation of all possible preferences.
Payoff function <span class="math">$&#92;displaystyle P&#92;left( &#92;beta &#92;right)=W&#92;left( &#92;beta=&#92;left( &#92;beta&#95;{i} &#92;right)&#95;{i &#92;in &#92;left&#92;{ 1,2 &#92;right&#92;}}, E=&#92;left( E^{i}&#92;in &#92;mathbb{R}&#95;{+}^{2} &#92;right)&#95;{i &#92;in&#92;left&#92;{ 1,2 &#92;right&#92;}}  &#92;right)$</span> is the Walrasian rule with preference <span class="math">$&#92;displaystyle &#92;beta$</span> and endowment <span class="math">$&#92;displaystyle E$</span>.
For each agent <span class="math">$&#92;displaystyle i$</span>, he choose a strategy <span class="math">$&#92;displaystyle &#92;beta&#95;{i}$</span> (a fake preference) to maximize his utility <span class="math">$&#92;displaystyle u&#95;{i}&#92;left( P^{i}&#92;left( &#92;beta &#92;right) &#92;right)$</span> after the realization of Walrasian rule.

## Nash Equilibrium with restriction <span class="math">$&#92;displaystyle &#92;mathcal{R}=&#92;mathcal{R}&#95;{CD}$</span>

### A simplified case: <span class="math">$&#92;displaystyle E=&#92;left( E^{i} &#92;right)$</span> where <span class="math">$&#92;displaystyle E^{1}=&#92;left( e&#95;{1},0 &#92;right)$</span> and <span class="math">$&#92;displaystyle E^{2}=&#92;left( 0,e&#95;{2} &#92;right)$</span>
The offer curve is a vertical or horizontal line.
The Nash equilibrium is <span class="math">$&#92;displaystyle &#92;beta&#95;{1}=&#92;left( u&#95;{1}^{L}=x&#95;{1} &#92;right)$</span> and <span class="math">$&#92;displaystyle &#92;beta&#95;{2}=&#92;left( u^{L}&#95;{2}=x&#95;{2} &#92;right)$</span> and the result is <span class="math">$&#92;displaystyle W&#92;left( &#92;beta,E &#92;right)=E$</span>, i.e. both agents consume their endowment and their utilities are 0.
![[Pasted image 20250421175342.png]]
### A general case: <span class="math">$&#92;displaystyle E=&#92;left( E^{i} &#92;right)$</span> where <span class="math">$&#92;displaystyle E^{1}=&#92;left( e&#95;{1},e&#95;{2} &#92;right)>0$</span> and <span class="math">$&#92;displaystyle E^{2}=&#92;left( w&#95;{1}-e&#95;{1}, w&#95;{2}-e&#95;{2} &#92;right)$</span>
Given announced preferences <span class="math">$&#92;displaystyle &#92;beta=&#92;left( &#92;beta&#95;{1} =x&#95;{1}^{a&#95;{1}}x&#95;{2}^{a&#95;{2}},&#92;beta&#95;{2}=y&#95;{1}^{b&#95;{1}}y&#95;{2}^{b&#95;{2}}&#92;right)$</span> , with normalization <span class="math">$&#92;displaystyle a&#95;{1}+a&#95;{2}=1, b&#95;{1}+b&#95;{2}=1$</span> and endowment <span class="math">$&#92;displaystyle E=&#92;left( E^{1}=&#92;left( e&#95;{1},e&#95;{2} &#92;right),E^{2}=&#92;left( w&#95;{1}-e&#95;{1},w&#95;{2}-e&#95;{2} &#92;right) &#92;right)$</span>, the Walrasian rule suggests:
<div class="math">$$
&#92;begin{align}
x&#95;{1}=a&#95;{1}e&#95;{1} &#92;left( 1+&#92;frac{p&#95;{2}e&#95;{2}}{p&#95;{1}e&#95;{1}} &#92;right)  & &  y&#95;{1}=b&#95;{1}&#92;left( w&#95;{1}-e&#95;{1} &#92;right)&#92;left( 1+&#92;frac{p&#95;{2}&#92;left( w&#95;{2}-e&#95;{2} &#92;right)}{p&#95;{1}&#92;left( w&#95;{1}-e&#95;{1} &#92;right)} &#92;right) &#92;&#92;
x&#95;{2}=a&#95;{2}e&#95;{2}&#92;left( &#92;frac{p&#95;{1}e&#95;{1}}{p&#95;{2}e&#95;{2}} +1&#92;right) &  & y&#95;{2}=b&#95;{2}&#92;left( w&#95;{2}-e&#95;{2} &#92;right)&#92;left( &#92;frac{p&#95;{1}&#92;left( w&#95;{1}-e&#95;{1} &#92;right)}{p&#95;{2}&#92;left( w&#95;{2}-e&#95;{2} &#92;right)}+1 &#92;right)
&#92;end{align}
$$</div>
where <span class="math">$&#92;displaystyle &#92;frac{p&#95;{2}}{p&#95;{1}}$</span> is defined by the following:
<div class="math">$$
&#92;frac{p&#95;{2}}{p&#95;{1}} = &#92;frac{b&#95;{2}w&#95;{1}+&#92;left( b&#95;{1}-a&#95;{1} &#92;right)e&#95;{1}}{b&#95;{1}w&#95;{2}-&#92;left( b&#95;{1}-a&#95;{1} &#92;right)e&#95;{2}}
$$</div>
Given agent <span class="math">$&#92;displaystyle b$</span> 's announcement <span class="math">$&#92;displaystyle &#92;beta&#95;{2}=y&#95;{1}^{b&#95;{1}}y&#95;{2}^{b&#95;{2}}$</span>, agent <span class="math">$&#92;displaystyle a$</span> chooses <span class="math">$&#92;displaystyle &#92;beta&#95;{1}=x&#95;{1}^{a&#95;{1}}x&#95;{2}^{y&#95;{2}}$</span> to maximize his true utility <span class="math">$&#92;displaystyle u&#95;{a}=x&#95;{1}^{at&#95;{1}}x&#95;{2}^{at&#95;{2}}$</span>:
<div class="math">$$
&#92;begin{align}
&#92;left( a&#95;{1}^{&#92;star},a&#95;{2}^{&#92;star} &#92;right) =   & &#92;mathop{&#92;arg&#92;max}&#92;limits&#95;{&#92;left( a&#95;{1},a&#95;{2} &#92;right)}    x&#95;{1}^{at&#95;{1}}x&#95;{2}^{at&#95;{2}} &#92;&#92;
s.t.  &  x&#95;{1}=a&#95;{1}e&#95;{1} &#92;left( 1+&#92;frac{p&#95;{2}e&#95;{2}}{p&#95;{1}e&#95;{1}} &#92;right) &#92;&#92;
 & x&#95;{2}=a&#95;{2}e&#95;{2}&#92;left( &#92;frac{p&#95;{1}e&#95;{1}}{p&#95;{2}e&#95;{2}} +1&#92;right) &#92;&#92;
 & &#92;frac{p&#95;{2}}{p&#95;{1}} = &#92;frac{b&#95;{2}w&#95;{1}+&#92;left( b&#95;{1}-a&#95;{1} &#92;right)e&#95;{1}}{b&#95;{1}w&#95;{2}-&#92;left( b&#95;{1}-a&#95;{1} &#92;right)e&#95;{2}}
&#92;end{align}
$$</div>
which is equivalent to the following
<div class="math">$$
&#92;begin{align}
&#92;left( a&#95;{1}^{&#92;star},a&#95;{2}^{&#92;star} &#92;right) =   & &#92;mathop{&#92;arg&#92;max}&#92;limits&#95;{&#92;left( a&#95;{1},a&#95;{2} &#92;right)}    &#92;left[a&#95;{1}e&#95;{1} &#92;left( 1+&#92;frac{p&#95;{2}e&#95;{2}}{p&#95;{1}e&#95;{1}} &#92;right)&#92;right]^{at&#95;{1}}&#92;left[a&#95;{2}e&#95;{2}&#92;left( &#92;frac{p&#95;{1}e&#95;{1}}{p&#95;{2}e&#95;{2}} +1&#92;right)&#92;right]^{at&#95;{2}} &#92;&#92;
s.t.  & &#92;frac{p&#95;{2}}{p&#95;{1}} = &#92;frac{b&#95;{2}w&#95;{1}+&#92;left( b&#95;{1}-a&#95;{1} &#92;right)e&#95;{1}}{b&#95;{1}w&#95;{2}-&#92;left( b&#95;{1}-a&#95;{1} &#92;right)e&#95;{2}} &#92;&#92;
&#92;end{align}
$$</div>
Symmetrically, agent <span class="math">$&#92;displaystyle b$</span> 's announcement <span class="math">$&#92;displaystyle (b&#95;{1}^{&#92;star},b&#95;{2}^{&#92;star})$</span> should also be the best response to agent a 's announcement <span class="math">$&#92;displaystyle (a&#95;{1},a&#95;{2})$</span>. Finally, we could pin down the Nash equilibrium: 
<div class="math">$$
&#92;begin{align}
&#92;left( a&#95;{1}^{&#92;star}, a&#95;{2}^{&#92;star} &#92;right)=BR&#92;left( b&#95;{1}^{&#92;star},b&#95;{2}^{&#92;star} &#92;right)  &  & &#92;left( b&#95;{1}^{&#92;star},b&#95;{2}^{&#92;star} &#92;right) = BR&#92;left( a&#95;{1}^{&#92;star}, a&#95;{2}^{&#92;star} &#92;right)
&#92;end{align}
$$</div>
We could get an intuition from the following graph:
![[Pasted image 20250421175356.png]]
With endowment <span class="math">$&#92;displaystyle&#92;left( e&#95;{1},e&#95;{2} &#92;right)$</span> and Cobb-Douglas parameters <span class="math">$&#92;displaystyle (a&#95;{1},a&#95;{2})$</span>, agent <span class="math">$&#92;displaystyle a$</span> 's offer curve is a hyperbola in the form: <span class="math">$&#92;displaystyle &#92;left(&#92;frac{x&#95;{1}}{a&#95;{1}e&#95;{1}}-1&#92;right) &#92;left(&#92;frac{x&#95;{2}}{a&#95;{2}e&#95;{2}}-1&#92;right)=1$</span> crossing the endowment point <span class="math">$&#92;displaystyle E$</span>. Symmetrically, agent <span class="math">$&#92;displaystyle b$</span>'s offer curve is another hyperbola crossing the endowment point <span class="math">$&#92;displaystyle E$</span>. Usually, the 2 offer curves have 2 intersections and the Walrasian rule is the intersection different with <span class="math">$&#92;displaystyle E$</span>. 
Given agent <span class="math">$&#92;displaystyle b$</span>'s offer curve, agent <span class="math">$&#92;displaystyle a$</span> is trying to announce a "fake" offer curve which could intersect with <span class="math">$&#92;displaystyle b$</span>'s offer curve on the top-right region. Symmetrically, agent <span class="math">$&#92;displaystyle b$</span> is also trying to make his offer curve intersecting with <span class="math">$&#92;displaystyle a$</span>'s offer curve on the bottom-left region. Finally, the Nash equilibrium is <span class="math">$&#92;displaystyle &#92;beta=&#92;left( &#92;beta&#95;{1}=x&#95;{1}^{a&#95;{1}}x&#95;{2}^{a&#95;{2}},&#92;beta&#95;{2}=y&#95;{1}^{b&#95;{1}}y&#95;{2}^{b&#95;{2}} &#92;right)$</span> with <span class="math">$&#92;displaystyle &#92;frac{a&#95;{1}e&#95;{2}}{a&#95;{2}e&#95;{1}}=&#92;frac{b&#95;{1}&#92;left( w&#95;{2}-e&#95;{2} &#92;right)}{b&#95;{2}&#92;left( w&#95;{1}-e&#95;{1} &#92;right)}$</span> such that the 2 offer curves contingent at their endowment point <span class="math">$&#92;displaystyle E$</span>. And the equilibrium allocation is the endowment allocation itself.

## All the Nash equilibrium allocation is in the intersection of 2 agents' upper contour sets: <span class="math">$&#92;displaystyle NE &#92;subset U^{1}&#92;left( E^{1} &#92;right) &#92;cap U^{2}&#92;left( E^{2} &#92;right)$</span> with classical preferences.
From the first welfare theorem, Walrasian rule leads to a Pareto efficient allocation and <span class="math">$&#92;displaystyle NE &#92;subset X-&#92;left( L^{1}&#92;left( E^{1} &#92;right) &#92;cap L^{2}&#92;left( E^{2} &#92;right) &#92;right)$</span>, where <span class="math">$&#92;displaystyle X$</span> represents the collection of all feasible allocations. The following is to show <span class="math">$&#92;displaystyle NE &#92;not&#92;subset L^{i}&#92;left( E^{i} &#92;right) &#92;cap U^{j}&#92;left( E^{j} &#92;right)$</span>.
By the way of contradiction, suppose there is a Nash equilibrium allocation <span class="math">$&#92;displaystyle x &#92;in L^{1}&#92;left( E^{1} &#92;right) &#92;cap U^{2}&#92;left( E^{2} &#92;right)$</span>, where agents have strategy <span class="math">$&#92;displaystyle &#92;beta=&#92;left( &#92;beta&#95;{1}, &#92;beta&#95;{2} &#92;right)$</span>. From definition of Walrasian rule, the segment connecting <span class="math">$&#92;displaystyle x$</span> and <span class="math">$&#92;displaystyle E$</span> separates 2 upper contour set defined by announced preferences <span class="math">$&#92;displaystyle &#92;beta$</span>. Based on classical assumption on strict monotone and strict convexity, the segment <span class="math">$&#92;displaystyle (x,E^{1})$</span> is in the strict contour set of <span class="math">$&#92;displaystyle x$</span> for agent 1: <span class="math">$&#92;displaystyle (x,E^{1}) &#92;in SU^{1}&#92;left( x &#92;right)$</span>. 
![[Pasted image 20250421175436.png]]
If agent 1 announces his true preference <span class="math">$&#92;displaystyle u&#95;{1}$</span>, the new allocation <span class="math">$&#92;displaystyle x'$</span> must be in the strict upper contour set of <span class="math">$&#92;displaystyle x$</span>: <span class="math">$&#92;displaystyle x' &#92;in SU^{1}&#92;left(  x&#92;right)$</span>. Thus, at current Nash equilibrium <span class="math">$&#92;displaystyle &#92;beta$</span>, agent 1 has incentive to deviate, leading to a contradiction.
