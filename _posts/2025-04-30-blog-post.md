## Walrasian rule is non-bossy in 2-good case if agent <span class="math">$&#92;displaystyle i$</span> 's Walrasian allocation is not equal to his endowment <span class="math">$&#92;displaystyle W&#95;{i}&#92;neq w&#95;{i}$</span>
Want to show: Given the number of good <span class="math">$&#92;displaystyle L=2$</span>, for all <span class="math">$&#92;displaystyle R &#92;in &#92;mathcal{R}^{N}$</span>, for all <span class="math">$&#92;displaystyle i &#92;in N$</span> and for all <span class="math">$&#92;displaystyle R&#95;{i} &#92;in &#92;mathcal{R}$</span>, if <span class="math">$&#92;displaystyle W&#95;{i}&#92;left( R&#95;{i}, R&#95;{-i} &#92;right)=W&#95;{i}&#92;left( R&#95;{i}',R&#95;{-i} &#92;right)&#92;neq w&#95;{i}$</span>, then <span class="math">$&#92;displaystyle W&#92;left( R&#95;{i}, R&#95;{-i} &#92;right)=W&#92;left( R&#95;{i}',R&#95;{-i} &#92;right)$</span>

Denote the equilibrium price vector for 2 Walrasian allocation <span class="math">$&#92;displaystyle W,W'$</span> as <span class="math">$&#92;displaystyle P,P' &#92;in &#92;Delta^{1}$</span>, which are in the simplex with degree of freedom equal to 1. Consider oth 2 preferences of agent <span class="math">$&#92;displaystyle i$</span> are strictly monotonic <span class="math">$&#92;displaystyle R&#95;{i}, R&#95;{i}' &#92;in &#92;mathcal{R&#95;{sm}}$</span>. By Walrasian rule, both 2 allocations <span class="math">$&#92;displaystyle W&#95;{i} W&#95;{i}'$</span> are on the budget lines in each case: 
<div class="math">$$
&#92;begin{align}
p &#92;cdot W&#95;{i}=p &#92;cdot e&#95;{i} &  & p' &#92;cdot W&#95;{i}=p' &#92;cdot e&#95;{i}
&#92;end{align}
$$</div>
From <span class="math">$&#92;displaystyle W&#95;{i}=W&#95;{i}'$</span>, we have
<div class="math">$$
&#92;left( p-p' &#92;right) &#92;cdot &#92;left( W&#95;{i}-e&#95;{i} &#92;right)=0
$$</div>
Since <span class="math">$&#92;displaystyle W&#95;{i}-e&#95;{i}&#92;in R^{2}&#92;setminus &#92;{ 0 &#92;}$</span> and <span class="math">$&#92;displaystyle p-p'&#92;in &#92;Delta^{1}$</span>, it is obvious that <span class="math">$&#92;displaystyle p=p'$</span> from the axiom in Euclidean geometry that there is a unique line connecting 2 distinct points <span class="math">$&#92;displaystyle W&#95;{i}, e&#95;{i}$</span> in 2 dimensional space.

For another agent <span class="math">$&#92;displaystyle j &#92;neq i$</span>, his preference <span class="math">$&#92;displaystyle R&#95;{j}$</span>, endowment <span class="math">$&#92;displaystyle W&#95;{j}$</span> and the price index <span class="math">$&#92;displaystyle p'=p$</span> all remain the same, then <span class="math">$&#92;displaystyle W&#95;{j}$</span> still solves the new utility maximization problem: <span class="math">$&#92;displaystyle W&#95;{j}=W&#95;{j}'$</span>. From the market clearing condition <span class="math">$&#92;displaystyle &#92;sum&#95;{i &#92;in N}W&#95;{i}=&#92;sum&#95;{i &#92;in N}W&#95;{i}'=&#92;sum&#95;{i &#92;in N}e&#95;{i}$</span>, we could verify that <span class="math">$&#92;displaystyle W&#95;{j}'=W&#95;{j}$</span> is the Walrasian allocation under <span class="math">$&#92;displaystyle (R&#95;{i}',R&#95;{-i})$</span>. 

Thus, <span class="math">$&#92;displaystyle W=W'$</span>.

## Walrasian rule is not non-bossy in 2-good case if agent <span class="math">$&#92;displaystyle i$</span> 's Walrasian allocation is equal to his endowment <span class="math">$&#92;displaystyle W&#95;{i} = e&#95;{i}$</span>
From above proof, if <span class="math">$&#92;displaystyle W&#95;{i}=e&#95;{i}$</span>, the equation <span class="math">$&#92;displaystyle (p-p')&#92;cdot&#92;left( W&#95;{i}-e&#95;{i} &#92;right)=0$</span> holds for all <span class="math">$&#92;displaystyle p,p'&#92;in &#92;Delta^{1}$</span>. Then it is not necessarily to have <span class="math">$&#92;displaystyle p=p'$</span>. The following is an example not satisfying non-bossy condition.

## Walrasian rule is not non-bossy for more goods 
From above proof, there are multiple <span class="math">$&#92;displaystyle p,p' &#92;in &#92;Delta^{L-1>1}$</span> to ensure <span class="math">$&#92;displaystyle (p-p')&#92;cdot&#92;left( W&#95;{i}-e&#95;{i} &#92;right)=0$</span> with <span class="math">$&#92;displaystyle W&#95;{i}-e&#95;{i} &#92;in &#92;mathbb{R}^{L}$</span>, based on the axiom that there are multiple hyperplanes connecting 2 points <span class="math">$&#92;displaystyle W&#95;{i}, e&#95;{i}$</span> in <span class="math">$&#92;displaystyle L&#92;left( L>2 &#92;right)$</span> dimensional space.
