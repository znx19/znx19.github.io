Set up:
=========
- 2 agent & 2 good Edgeworth economy
- Total resource: $\displaystyle M=\left( M_{1},M_{2} \right)\in \mathbb{R}_{++}^{2}$

Part 1: If preferences are continuous, strictly monotonic, strictly convex, and homothetic, then the Pareto set is either a doubly visible curve or a segment connecting origins.
======

Case 1: If there is a point $\displaystyle x=\left( x_{1},x_{2} \right)$ from Pareto set on the segment connecting the origins: $\exists x=\left( x_{1},x_{2} \right)\in P, s.t. \displaystyle \frac{x_{2}}{x_{1}}=\frac{M_{2}}{M_{1}}$, then the Pareto set is the segment connecting origins: $\displaystyle \forall y \in P, \frac{y_{2}}{y_{1}}=\frac{M_{2}}{M_{1}}$
---------------

By the way of contradiction, suppose there is a point $\displaystyle x$ from Pareto set on the segment from $\displaystyle O_{1}$ to $\displaystyle O_{2}$, and there is another point $\displaystyle y$ from Pareto set not on that segment.
Since both 2 preferences are strictly convex, the Pareto equivalent class must be singleton. Thus, from the perspective of agent 1, either $\displaystyle y$ is preferred to $\displaystyle x$, or the other way, holds. Without loss of generality, suppose $\displaystyle y$ is preferred to x for agent 1, $\displaystyle y>_{1}x$.
Since both $\displaystyle x$ and $\displaystyle y$ are Pareto efficient, we have x is preferred to y for agent 2, $\displaystyle y<_{2}x$.
Denote another 2 allocations on the segment connecting origins as $\displaystyle z$ and $\displaystyle t$, such that z is equivalent to $\displaystyle y$ for agent 2, $\displaystyle z \sim_{2}y$ and $\displaystyle t$ is equivalent to $\displaystyle y$ for agent 1, $\displaystyle t\sim_{1}y$.
From homothetic preference of agent 2, we have $\displaystyle z\geq t$. Otherwise, we could find an allocation $\displaystyle s$ satisfying $\displaystyle s\sim_{2}t$ from $\displaystyle z\sim_{2}y$, denoted by red points in the following graph. 
![[Pasted image 20250405161631.png]]
Notice that $\displaystyle s$ is on the segment from $\displaystyle y$ to $\displaystyle O_{2}$, then $\displaystyle s>y$. From strict monotone of agent 1's preference, he should prefer $\displaystyle s$ to $\displaystyle y$: $\displaystyle s>_{1}y$. Given $\displaystyle y\sim_{2}t$, we have $\displaystyle s$ Pareto dominates y, leading to a contradiction to the efficiency of $\displaystyle y$.

If $\displaystyle z>t$, then $\displaystyle z$ Pareto dominates$\displaystyle y$, contradicting to the efficiency of $\displaystyle y$. Otherwise, $\displaystyle z=t$, a strictly convex combination of $\displaystyle z$ and $\displaystyle y$ also dominates $\displaystyle y$ from strict convex of 2 preferences, again contradicting to the efficiency of $\displaystyle y$. 

Case 2: If there is not a point $\displaystyle x=\left( x_{1},x_{2} \right)$ on the segment connecting the origins: $\displaystyle \forall x \in P, \frac{x_{2}}{x_{1}}\not=\frac{M_{2}}{M_{1}}$, then the Pareto set is doubly visible: $\displaystyle \forall x,y \in P, \frac{x_{2}}{x_{1}}\not=\frac{y_{2}}{y_{1}}\cap\frac{M_2-x_{2}}{M_{1}-x_{1}}\not=\frac{M_{2}-y_{2}}{M_{1}-y_{1}}$
------------------

By the way of contradiction, suppose there is are 2 points $\displaystyle x$ and $\displaystyle y$ from Pareto set on the same line starting from $\displaystyle O_{1}$. Without loss of generality, suppose $\displaystyle y>x$.

Denote another 2 allocations on the segment connecting $\displaystyle x$ and $\displaystyle O_{2}$ as $\displaystyle z$ and $\displaystyle t$, such that z is equivalent to $\displaystyle y$ for agent 2, $\displaystyle z \sim_{2}y$ and $\displaystyle t$ is equivalent to $\displaystyle y$ for agent 1, $\displaystyle t\sim_{1}y$.
From homothetic preference of agent 2, we have $\displaystyle z\geq t$. Otherwise, we could find an allocation $\displaystyle s$ satisfying $\displaystyle s\sim_{2}t$ from $\displaystyle z\sim_{2}y$, denoted by red points in the following graph. 
![[Pasted image 20250405161653.png]]
Notice that $\displaystyle s$ is on the segment from $\displaystyle y$ to $\displaystyle O_{2}$, then $\displaystyle s>y$. From strict monotone of agent 1's preference, he should prefer $\displaystyle s$ to $\displaystyle y$: $\displaystyle s>_{1}y$. Given $\displaystyle y\sim_{2}t$, we have $\displaystyle s$ Pareto dominates y, leading to a contradiction to the efficiency of $\displaystyle y$.

If $\displaystyle z>t$, then $\displaystyle z$ Pareto dominates$\displaystyle y$, contradicting to the efficiency of $\displaystyle y$. Otherwise, $\displaystyle z=t$, a strictly convex combination of $\displaystyle z$ and $\displaystyle y$ also dominates $\displaystyle y$ from strict convex of 2 preferences, again contradicting to the efficiency of $\displaystyle y$. 

The proof on the visibility from the other origin $\displaystyle O_{2}$ is similar, and there is no need to repeat this process again.



Given any double visible curve, there is a pair of homothetic preferences such that the Pareto set of the resulting economy is the curve.
=============

For each $\displaystyle x \in P$, denote $\displaystyle (1,a\left( x \right))$ as the normal vector of the Pareto curve at point $\displaystyle x$ to be a function on $\displaystyle x$. Furthermore, $\displaystyle a$ is a function on $\displaystyle \frac{x_{2}}{x_{1}}$ since for each value of $\displaystyle \frac{x_{2}}{x_{1}}$, there is no more than 1 point $\displaystyle x$ satisfying its ratio of 2 coordinates equal to $\displaystyle \frac{x_{2}}{x_{1}}$, based on the visibility from $\displaystyle O_{1}$. Symmetrically, $\displaystyle a$ is also a function on $\displaystyle \frac{y_{2}}{y_{1}}$, denoted by $\displaystyle b\left( \frac{y_{2}}{y_{1}} \right)$, based on the visibility from $\displaystyle O_{2}$. Since a doubly visible curve is not necessarily concave or convex, $\displaystyle a\left( \frac{x_{2}}{x_{1}} \right)$ and $\displaystyle b\left( \frac{y_{2}}{y_{1}} \right)$ are also not necessarily to be monotonic, but it is easy to show:
$$
\begin{align}
a'\left( \frac{x_{2}}{x_{1}} \right) \left\{ a\left( \frac{x_{2}}{x_{1}} \right) - \frac{x_{2}}{x_{1}} \right\} \frac{1}{x_{1}} \geq 0 \\
b'\left( \frac{y_{2}}{y_{1}} \right) \left\{ b\left( \frac{y_{2}}{y_{1}} \right) - \frac{y_{2}}{y_{1}} \right\} \frac{1}{y_{1}} \geq 0
\end{align}
$$

According to the specific shape of the curve, there is a natural region for the function $\displaystyle a$ to be well-defined: $\displaystyle \frac{x_{2}}{x_{1}} \in Interval_{1}$ and $\displaystyle \frac{y_{2}}{y_{1}} \in Interval_{2}$, represented by the red dashed line in the following graph.
![[Pasted image 20250405161714.png]]
Fix $\displaystyle a \in[0,M_{1}]$, define indifference curves $\displaystyle IC^{1}, IC^{2}$ passing through the point $\displaystyle\left(a, \frac{M_{2}}{M_{1}}a \right)$ on regions $\displaystyle \frac{x_{2}}{x_{1}} \in Interval_{1}$ and $\displaystyle \frac{y_{2}}{y_{1}} \in Interval_{2}$ respectively:
$$
\begin{align}
& \frac{ \partial IC^{1}\left( x_{1},x_{2} \right) }{ \partial x_{1} } = \frac{ \partial IC^{1}\left( x_{1},x_{2} \right) }{ \partial x_{2} } a\left( \frac{x_{2}}{x_{1}} \right) & \text{inital condition: } IC^{1}\left( a, \frac{M_{2}}{M_{1}}a \right)=0 \\
& \frac{ \partial IC^{2}\left( y_{1},y_{2} \right) }{ \partial y_{1} } = \frac{ \partial IC^{2}\left( y_{1},y_{2} \right) }{ \partial y_{2} } a\left( \frac{y_{2}}{y_{1}} \right) & \text{inital condition: } IC^{1}\left( a, \frac{M_{2}}{M_{1}}a \right)=0 \\
\end{align}
$$
Solve the above PDEs, we get specific function forms for indifference curves passing through the point $\displaystyle (a, \frac{M_{2}}{M_{1}}a)$:
$$
\begin{align}
& IC^{1}\left( x_{1},x_{2} \right)=0 & \forall \frac{x_{2}}{x_{1}}\in Interval_{1} \\
& IC^{2}\left( y_{1},y_{2} \right)=0 & \forall \frac{y_{2}}{y_{1}}\in Interval_{2} \\
\end{align}
$$
For the consumption bundles which are not covered by the natural regions, simply extend $\displaystyle IC^{1}$ and $\displaystyle IC^{2}$ to be parallel to the axis, represented by blue solid lines in the following graph. 
![[Pasted image 20250405161726.png]]
For each $\displaystyle a \in [0,M_{1}]$, repeat the above process to get the indifference curve crossing the point $\displaystyle\left(a, \frac{M_{2}}{M_{1}}a \right)$. Finally we get 2 bunches of indifference curves $\displaystyle\left\{ IC^{1}_{a} \right\}_{a \in [0,M_{1}]}$ and $\displaystyle\left\{ IC^{2}_{a} \right\}_{a \in [0,M_{1}]}$. 

For strict monotone of preferences, define utilities as:
$$
\begin{align}
 & u^{1}\left( x_{1},x_{2} \right) = a & \text{  if   } IC^{1}_{a}\left( x_{1},x_{2} \right)=0 \\
 & u^{2}\left( y_{1},y_{2} \right) = M_{1}-a & \text{  if   } IC^{2}_{a}\left( y_{1},y_{2} \right)=0 \\
\end{align}
$$

From constructions of indifference curves and utilities, it is obvious that agent 1 has homothetic preference:
$$
\begin{align}
 & \text{If } \frac{x_{2}}{x_{1}} \in Interval_{1}:  & \frac{dx_{2}}{dx_{1}}= \frac{\frac{ \partial IC^{1}\left( x_{1},x_{2} \right) }{ \partial x_{1} }}{\frac{ \partial IC^{1}\left( x_{1},x_{2} \right) }{ \partial x_{2} }} = a\left( \frac{x_{2}}{x_{1}} \right) \\
 & \text{If } \frac{x_{2}}{x_{1}} > \mathop{\max} \left\{ Interval_{1} \right\}:  & \frac{dx_{2}}{dx_{1}}= \frac{\frac{ \partial IC^{1}\left( x_{1},x_{2} \right) }{ \partial x_{1} }}{\frac{ \partial IC^{1}\left( x_{1},x_{2} \right) }{ \partial x_{2} }} = \infty \\ \\
 & \text{If } \frac{x_{2}}{x_{1}} < \mathop{\min} \left\{ Interval_{1} \right\}:  & \frac{dx_{2}}{dx_{1}}= \frac{\frac{ \partial IC^{1}\left( x_{1},x_{2} \right) }{ \partial x_{1} }}{\frac{ \partial IC^{1}\left( x_{1},x_{2} \right) }{ \partial x_{2} }} = 0 \\
\end{align}
$$
Similarly, agent 2 also has homothetic preference.

Notice that both 2 preferences are convex
$$
\begin{align}
\frac{d^{2}x_{2}}{dx_{1}^{2}}=a'\left( \frac{x_{2}}{x_{1}} \right) \left[ a\left( \frac{x_{2}}{x_{1}} \right)-\frac{x_{2}}{x_{1}} \right] \frac{1}{x_{1}}\geq 0 \\
\frac{d^{2}y_{2}}{dy_{1}^{2}}=b'\left( \frac{y_{2}}{y_{1}} \right) \left[ b\left( \frac{y_{2}}{y_{1}} \right)-\frac{y_{2}}{y_{1}} \right] \frac{1}{y_{1}}\geq 0 \\
\end{align}
$$
Then for each $\displaystyle x$ from the doubly visible curve, the line generated from normal vector of the curve at $\displaystyle x$ separates the strict upper contour set of agent 1 and agent 2, and such a curve connects 2 origins, exhausting all the possible utilities one agent could gain. Thus, the Pareto set of the economy with above utilities is this curve.
