Set up:
=========
- 2 agent & 2 good Edgeworth economy
- Total resource: <span class="math">$&#92;displaystyle M=&#92;left( M&#95;{1},M&#95;{2} &#92;right)&#92;in &#92;mathbb{R}&#95;{++}^{2}$</span>

Part 1: If preferences are continuous, strictly monotonic, strictly convex, and homothetic, then the Pareto set is either a doubly visible curve or a segment connecting origins.
======

Case 1: If there is a point <span class="math">$&#92;displaystyle x=&#92;left( x&#95;{1},x&#95;{2} &#92;right)$</span> from Pareto set on the segment connecting the origins: <span class="math">$&#92;exists x=&#92;left( x&#95;{1},x&#95;{2} &#92;right)&#92;in P, s.t. &#92;displaystyle &#92;frac{x&#95;{2}}{x&#95;{1}}=&#92;frac{M&#95;{2}}{M&#95;{1}}$</span>, then the Pareto set is the segment connecting origins: <span class="math">$&#92;displaystyle &#92;forall y &#92;in P, &#92;frac{y&#95;{2}}{y&#95;{1}}=&#92;frac{M&#95;{2}}{M&#95;{1}}$</span>
---------------

By the way of contradiction, suppose there is a point <span class="math">$&#92;displaystyle x$</span> from Pareto set on the segment from <span class="math">$&#92;displaystyle O&#95;{1}$</span> to <span class="math">$&#92;displaystyle O&#95;{2}$</span>, and there is another point <span class="math">$&#92;displaystyle y$</span> from Pareto set not on that segment.
Since both 2 preferences are strictly convex, the Pareto equivalent class must be singleton. Thus, from the perspective of agent 1, either <span class="math">$&#92;displaystyle y$</span> is preferred to <span class="math">$&#92;displaystyle x$</span>, or the other way, holds. Without loss of generality, suppose <span class="math">$&#92;displaystyle y$</span> is preferred to x for agent 1, <span class="math">$&#92;displaystyle y>&#95;{1}x$</span>.
Since both <span class="math">$&#92;displaystyle x$</span> and <span class="math">$&#92;displaystyle y$</span> are Pareto efficient, we have x is preferred to y for agent 2, <span class="math">$&#92;displaystyle y<&#95;{2}x$</span>.
Denote another 2 allocations on the segment connecting origins as <span class="math">$&#92;displaystyle z$</span> and <span class="math">$&#92;displaystyle t$</span>, such that z is equivalent to <span class="math">$&#92;displaystyle y$</span> for agent 2, <span class="math">$&#92;displaystyle z &#92;sim&#95;{2}y$</span> and <span class="math">$&#92;displaystyle t$</span> is equivalent to <span class="math">$&#92;displaystyle y$</span> for agent 1, <span class="math">$&#92;displaystyle t&#92;sim&#95;{1}y$</span>.
From homothetic preference of agent 2, we have <span class="math">$&#92;displaystyle z&#92;geq t$</span>. Otherwise, we could find an allocation <span class="math">$&#92;displaystyle s$</span> satisfying <span class="math">$&#92;displaystyle s&#92;sim&#95;{2}t$</span> from <span class="math">$&#92;displaystyle z&#92;sim&#95;{2}y$</span>, denoted by red points in the following graph. 
![[Pasted image 20250405161631.png]]
Notice that <span class="math">$&#92;displaystyle s$</span> is on the segment from <span class="math">$&#92;displaystyle y$</span> to <span class="math">$&#92;displaystyle O&#95;{2}$</span>, then <span class="math">$&#92;displaystyle s>y$</span>. From strict monotone of agent 1's preference, he should prefer <span class="math">$&#92;displaystyle s$</span> to <span class="math">$&#92;displaystyle y$</span>: <span class="math">$&#92;displaystyle s>&#95;{1}y$</span>. Given <span class="math">$&#92;displaystyle y&#92;sim&#95;{2}t$</span>, we have <span class="math">$&#92;displaystyle s$</span> Pareto dominates y, leading to a contradiction to the efficiency of <span class="math">$&#92;displaystyle y$</span>.

If <span class="math">$&#92;displaystyle z>t$</span>, then <span class="math">$&#92;displaystyle z$</span> Pareto dominates<span class="math">$&#92;displaystyle y$</span>, contradicting to the efficiency of <span class="math">$&#92;displaystyle y$</span>. Otherwise, <span class="math">$&#92;displaystyle z=t$</span>, a strictly convex combination of <span class="math">$&#92;displaystyle z$</span> and <span class="math">$&#92;displaystyle y$</span> also dominates <span class="math">$&#92;displaystyle y$</span> from strict convex of 2 preferences, again contradicting to the efficiency of <span class="math">$&#92;displaystyle y$</span>. 

Case 2: If there is not a point <span class="math">$&#92;displaystyle x=&#92;left( x&#95;{1},x&#95;{2} &#92;right)$</span> on the segment connecting the origins: <span class="math">$&#92;displaystyle &#92;forall x &#92;in P, &#92;frac{x&#95;{2}}{x&#95;{1}}&#92;not=&#92;frac{M&#95;{2}}{M&#95;{1}}$</span>, then the Pareto set is doubly visible: <span class="math">$&#92;displaystyle &#92;forall x,y &#92;in P, &#92;frac{x&#95;{2}}{x&#95;{1}}&#92;not=&#92;frac{y&#95;{2}}{y&#95;{1}}&#92;cap&#92;frac{M&#95;2-x&#95;{2}}{M&#95;{1}-x&#95;{1}}&#92;not=&#92;frac{M&#95;{2}-y&#95;{2}}{M&#95;{1}-y&#95;{1}}$</span>
------------------

By the way of contradiction, suppose there is are 2 points <span class="math">$&#92;displaystyle x$</span> and <span class="math">$&#92;displaystyle y$</span> from Pareto set on the same line starting from <span class="math">$&#92;displaystyle O&#95;{1}$</span>. Without loss of generality, suppose <span class="math">$&#92;displaystyle y>x$</span>.

Denote another 2 allocations on the segment connecting <span class="math">$&#92;displaystyle x$</span> and <span class="math">$&#92;displaystyle O&#95;{2}$</span> as <span class="math">$&#92;displaystyle z$</span> and <span class="math">$&#92;displaystyle t$</span>, such that z is equivalent to <span class="math">$&#92;displaystyle y$</span> for agent 2, <span class="math">$&#92;displaystyle z &#92;sim&#95;{2}y$</span> and <span class="math">$&#92;displaystyle t$</span> is equivalent to <span class="math">$&#92;displaystyle y$</span> for agent 1, <span class="math">$&#92;displaystyle t&#92;sim&#95;{1}y$</span>.
From homothetic preference of agent 2, we have <span class="math">$&#92;displaystyle z&#92;geq t$</span>. Otherwise, we could find an allocation <span class="math">$&#92;displaystyle s$</span> satisfying <span class="math">$&#92;displaystyle s&#92;sim&#95;{2}t$</span> from <span class="math">$&#92;displaystyle z&#92;sim&#95;{2}y$</span>, denoted by red points in the following graph. 
![[Pasted image 20250405161653.png]]
Notice that <span class="math">$&#92;displaystyle s$</span> is on the segment from <span class="math">$&#92;displaystyle y$</span> to <span class="math">$&#92;displaystyle O&#95;{2}$</span>, then <span class="math">$&#92;displaystyle s>y$</span>. From strict monotone of agent 1's preference, he should prefer <span class="math">$&#92;displaystyle s$</span> to <span class="math">$&#92;displaystyle y$</span>: <span class="math">$&#92;displaystyle s>&#95;{1}y$</span>. Given <span class="math">$&#92;displaystyle y&#92;sim&#95;{2}t$</span>, we have <span class="math">$&#92;displaystyle s$</span> Pareto dominates y, leading to a contradiction to the efficiency of <span class="math">$&#92;displaystyle y$</span>.

If <span class="math">$&#92;displaystyle z>t$</span>, then <span class="math">$&#92;displaystyle z$</span> Pareto dominates<span class="math">$&#92;displaystyle y$</span>, contradicting to the efficiency of <span class="math">$&#92;displaystyle y$</span>. Otherwise, <span class="math">$&#92;displaystyle z=t$</span>, a strictly convex combination of <span class="math">$&#92;displaystyle z$</span> and <span class="math">$&#92;displaystyle y$</span> also dominates <span class="math">$&#92;displaystyle y$</span> from strict convex of 2 preferences, again contradicting to the efficiency of <span class="math">$&#92;displaystyle y$</span>. 

The proof on the visibility from the other origin <span class="math">$&#92;displaystyle O&#95;{2}$</span> is similar, and there is no need to repeat this process again.



Given any double visible curve, there is a pair of homothetic preferences such that the Pareto set of the resulting economy is the curve.
=============

For each <span class="math">$&#92;displaystyle x &#92;in P$</span>, denote <span class="math">$&#92;displaystyle (1,a&#92;left( x &#92;right))$</span> as the normal vector of the Pareto curve at point <span class="math">$&#92;displaystyle x$</span> to be a function on <span class="math">$&#92;displaystyle x$</span>. Furthermore, <span class="math">$&#92;displaystyle a$</span> is a function on <span class="math">$&#92;displaystyle &#92;frac{x&#95;{2}}{x&#95;{1}}$</span> since for each value of <span class="math">$&#92;displaystyle &#92;frac{x&#95;{2}}{x&#95;{1}}$</span>, there is no more than 1 point <span class="math">$&#92;displaystyle x$</span> satisfying its ratio of 2 coordinates equal to <span class="math">$&#92;displaystyle &#92;frac{x&#95;{2}}{x&#95;{1}}$</span>, based on the visibility from <span class="math">$&#92;displaystyle O&#95;{1}$</span>. Symmetrically, <span class="math">$&#92;displaystyle a$</span> is also a function on <span class="math">$&#92;displaystyle &#92;frac{y&#95;{2}}{y&#95;{1}}$</span>, denoted by <span class="math">$&#92;displaystyle b&#92;left( &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right)$</span>, based on the visibility from <span class="math">$&#92;displaystyle O&#95;{2}$</span>. Since a doubly visible curve is not necessarily concave or convex, <span class="math">$&#92;displaystyle a&#92;left( &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right)$</span> and <span class="math">$&#92;displaystyle b&#92;left( &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right)$</span> are also not necessarily to be monotonic, but it is easy to show:
<div class="math">$$
&#92;begin{align}
a'&#92;left( &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right) &#92;left&#92;{ a&#92;left( &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right) - &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right&#92;} &#92;frac{1}{x&#95;{1}} &#92;geq 0 &#92;&#92;
b'&#92;left( &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right) &#92;left&#92;{ b&#92;left( &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right) - &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right&#92;} &#92;frac{1}{y&#95;{1}} &#92;geq 0
&#92;end{align}
$$</div>

According to the specific shape of the curve, there is a natural region for the function <span class="math">$&#92;displaystyle a$</span> to be well-defined: <span class="math">$&#92;displaystyle &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;in Interval&#95;{1}$</span> and <span class="math">$&#92;displaystyle &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;in Interval&#95;{2}$</span>, represented by the red dashed line in the following graph.
![[Pasted image 20250405161714.png]]
Fix <span class="math">$&#92;displaystyle a &#92;in[0,M&#95;{1}]$</span>, define indifference curves <span class="math">$&#92;displaystyle IC^{1}, IC^{2}$</span> passing through the point <span class="math">$&#92;displaystyle&#92;left(a, &#92;frac{M&#95;{2}}{M&#95;{1}}a &#92;right)$</span> on regions <span class="math">$&#92;displaystyle &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;in Interval&#95;{1}$</span> and <span class="math">$&#92;displaystyle &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;in Interval&#95;{2}$</span> respectively:
<div class="math">$$
&#92;begin{align}
& &#92;frac{ &#92;partial IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) }{ &#92;partial x&#95;{1} } = &#92;frac{ &#92;partial IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) }{ &#92;partial x&#95;{2} } a&#92;left( &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right) & &#92;text{inital condition: } IC^{1}&#92;left( a, &#92;frac{M&#95;{2}}{M&#95;{1}}a &#92;right)=0 &#92;&#92;
& &#92;frac{ &#92;partial IC^{2}&#92;left( y&#95;{1},y&#95;{2} &#92;right) }{ &#92;partial y&#95;{1} } = &#92;frac{ &#92;partial IC^{2}&#92;left( y&#95;{1},y&#95;{2} &#92;right) }{ &#92;partial y&#95;{2} } a&#92;left( &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right) & &#92;text{inital condition: } IC^{1}&#92;left( a, &#92;frac{M&#95;{2}}{M&#95;{1}}a &#92;right)=0 &#92;&#92;
&#92;end{align}
$$</div>
Solve the above PDEs, we get specific function forms for indifference curves passing through the point <span class="math">$&#92;displaystyle (a, &#92;frac{M&#95;{2}}{M&#95;{1}}a)$</span>:
<div class="math">$$
&#92;begin{align}
& IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right)=0 & &#92;forall &#92;frac{x&#95;{2}}{x&#95;{1}}&#92;in Interval&#95;{1} &#92;&#92;
& IC^{2}&#92;left( y&#95;{1},y&#95;{2} &#92;right)=0 & &#92;forall &#92;frac{y&#95;{2}}{y&#95;{1}}&#92;in Interval&#95;{2} &#92;&#92;
&#92;end{align}
$$</div>
For the consumption bundles which are not covered by the natural regions, simply extend <span class="math">$&#92;displaystyle IC^{1}$</span> and <span class="math">$&#92;displaystyle IC^{2}$</span> to be parallel to the axis, represented by blue solid lines in the following graph. 
![[Pasted image 20250405161726.png]]
For each <span class="math">$&#92;displaystyle a &#92;in [0,M&#95;{1}]$</span>, repeat the above process to get the indifference curve crossing the point <span class="math">$&#92;displaystyle&#92;left(a, &#92;frac{M&#95;{2}}{M&#95;{1}}a &#92;right)$</span>. Finally we get 2 bunches of indifference curves <span class="math">$&#92;displaystyle&#92;left&#92;{ IC^{1}&#95;{a} &#92;right&#92;}&#95;{a &#92;in [0,M&#95;{1}]}$</span> and <span class="math">$&#92;displaystyle&#92;left&#92;{ IC^{2}&#95;{a} &#92;right&#92;}&#95;{a &#92;in [0,M&#95;{1}]}$</span>. 

For strict monotone of preferences, define utilities as:
<div class="math">$$
&#92;begin{align}
 & u^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) = a & &#92;text{  if   } IC^{1}&#95;{a}&#92;left( x&#95;{1},x&#95;{2} &#92;right)=0 &#92;&#92;
 & u^{2}&#92;left( y&#95;{1},y&#95;{2} &#92;right) = M&#95;{1}-a & &#92;text{  if   } IC^{2}&#95;{a}&#92;left( y&#95;{1},y&#95;{2} &#92;right)=0 &#92;&#92;
&#92;end{align}
$$</div>

From constructions of indifference curves and utilities, it is obvious that agent 1 has homothetic preference:
<div class="math">$$
&#92;begin{align}
 & &#92;text{If } &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;in Interval&#95;{1}:  & &#92;frac{dx&#95;{2}}{dx&#95;{1}}= &#92;frac{&#92;frac{ &#92;partial IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) }{ &#92;partial x&#95;{1} }}{&#92;frac{ &#92;partial IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) }{ &#92;partial x&#95;{2} }} = a&#92;left( &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right) &#92;&#92;
 & &#92;text{If } &#92;frac{x&#95;{2}}{x&#95;{1}} > &#92;mathop{&#92;max} &#92;left&#92;{ Interval&#95;{1} &#92;right&#92;}:  & &#92;frac{dx&#95;{2}}{dx&#95;{1}}= &#92;frac{&#92;frac{ &#92;partial IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) }{ &#92;partial x&#95;{1} }}{&#92;frac{ &#92;partial IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) }{ &#92;partial x&#95;{2} }} = &#92;infty &#92;&#92; &#92;&#92;
 & &#92;text{If } &#92;frac{x&#95;{2}}{x&#95;{1}} < &#92;mathop{&#92;min} &#92;left&#92;{ Interval&#95;{1} &#92;right&#92;}:  & &#92;frac{dx&#95;{2}}{dx&#95;{1}}= &#92;frac{&#92;frac{ &#92;partial IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) }{ &#92;partial x&#95;{1} }}{&#92;frac{ &#92;partial IC^{1}&#92;left( x&#95;{1},x&#95;{2} &#92;right) }{ &#92;partial x&#95;{2} }} = 0 &#92;&#92;
&#92;end{align}
$$</div>
Similarly, agent 2 also has homothetic preference.

Notice that both 2 preferences are convex
<div class="math">$$
&#92;begin{align}
&#92;frac{d^{2}x&#95;{2}}{dx&#95;{1}^{2}}=a'&#92;left( &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right) &#92;left[ a&#92;left( &#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right)-&#92;frac{x&#95;{2}}{x&#95;{1}} &#92;right] &#92;frac{1}{x&#95;{1}}&#92;geq 0 &#92;&#92;
&#92;frac{d^{2}y&#95;{2}}{dy&#95;{1}^{2}}=b'&#92;left( &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right) &#92;left[ b&#92;left( &#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right)-&#92;frac{y&#95;{2}}{y&#95;{1}} &#92;right] &#92;frac{1}{y&#95;{1}}&#92;geq 0 &#92;&#92;
&#92;end{align}
$$</div>
Then for each <span class="math">$&#92;displaystyle x$</span> from the doubly visible curve, the line generated from normal vector of the curve at <span class="math">$&#92;displaystyle x$</span> separates the strict upper contour set of agent 1 and agent 2, and such a curve connects 2 origins, exhausting all the possible utilities one agent could gain. Thus, the Pareto set of the economy with above utilities is this curve.
