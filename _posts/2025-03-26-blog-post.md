# There is a pair <span class="math">$&#92;left( u&#95;{1}, u&#95;{2} &#92;right): &#92;mathbb{R}&#95;{+}&#92;to &#92;mathbb{R}&#95;{+}$</span> and <span class="math">$M&#92;in &#92;mathbb{R}&#95;{+}$</span> such that the image of the feasible set of the economy <span class="math">$&#92;left( u&#95;{1}, u&#95;{2}, M &#92;right)$</span> is <span class="math">$S$</span>. 


For any convex and compact subset <span class="math">$S &#92;in &#92;mathbb{R}&#95;{+}^{2}$</span>, define the smallest convex and comprehensive hull containing <span class="math">$S$</span> as <span class="math">$con.comp&#92;left( S &#92;right):=&#92;left&#92;{ x &#92;in &#92;mathbb{R}^{2} &#92;text{ : } x&#95;{i}&#92;leq D&#95;{i}&#92;left( S &#92;right) &#92;text{, } &#92;forall i = 1, 2 &#92;right&#92;}$</span>, where the maximal utility of each agent <span class="math">$i$</span> is defined as <span class="math">$D&#95;{i}&#92;left( S &#92;right):=max&#92;left&#92;{ x&#95;{i} &#92;text{ : } x &#92;in S &#92;right&#92;}$</span>. Since there is at least one point x such that <span class="math">$x>0$</span>, we have <span class="math">$D&#95;{i}&#92;left( S &#92;right)>0$</span> and effective feasible set <span class="math">$con.comp&#92;left( S &#92;right) &#92;cap &#92;mathbb{R}&#95;{+}^{2}$</span> is non-degenerate (a 2-dimensional set).

Denote the function form of the frontier of the effective feasible set <span class="math">$con.comp&#92;left( S &#92;right) &#92;cap &#92;mathbb{R}&#95;{+}^{2}$</span> as <span class="math">$&#92;Phi&#92;left( v&#95;{1}, v&#95;{2} &#92;right)=0$</span>, where <span class="math">$&#92;left( v&#95;{1}, v&#95;{2} &#92;right) &#92;in &#92;mathbb{R}&#95;{+}^{2}$</span> represents the assigned utilities to agent 1 and 2. 

For 1-good bargaining problem, each allocation on resource <span class="math">$&#92;left( x&#95;{1}, x&#95;{2} &#92;right)$</span> such that <span class="math">$x&#95;{1}+x&#95;{2}=M$</span> is Pareto Optimal and the assigned utility <span class="math">$&#92;left( u&#95;{1}&#92;left( x&#95;{1} &#92;right),u&#95;{2}&#92;left( x&#95;{2} &#92;right) &#92;right)$</span> is on the frontier of the feasible set. Thus, we have

<div class="math">$$
&#92;begin{align*}
& v&#95;{1} = u&#95;{1}&#92;left( M-u&#95;{2}^{-1}&#92;left( v&#95;{2} &#92;right) &#92;right) &#92;implies &#92;Phi&#92;left( u&#95;{1}&#92;left( M-u&#95;{2}^{-1}&#92;left( v&#95;{2} &#92;right) &#92;right), v&#95;{2} &#92;right)=0 &#92;&#92;
& v&#95;{2} = u&#95;{2}&#92;left( M-u&#95;{1}^{-1}&#92;left( v&#95;{1} &#92;right) &#92;right) &#92;implies &#92;Phi&#92;left( v&#95;{1},u&#95;{2}&#92;left( M-u&#95;{1}^{-1}&#92;left( v&#95;{1} &#92;right) &#92;right) &#92;right)=0
&#92;end{align*}
$$</div>

Denote <span class="math">$u&#95;{1}&#92;left( x&#95;{1} &#92;right)=v&#95;{1}$</span>, <span class="math">$u&#95;{2}&#92;left( x&#95;{2} &#92;right)=v&#95;{2}$</span> and <span class="math">$x&#95;{1}+x&#95;{2}=M$</span>. Then differentiate the above 2 equations, we have

<div class="math">$$
&#92;Phi&#95;{1}&#92;left( v&#95;{1},v&#95;{2} &#92;right) &#92;frac{u&#95;{1}'&#92;left( x&#95;{1} &#92;right)}{u&#95;{2}'&#92;left( x&#95;{2} &#92;right)} = &#92;Phi&#95;{2}&#92;left( v&#95;{1},v&#95;{2} &#92;right)
$$</div>

Applying <span class="math">$x&#95;{1}+x&#95;{2}=M$</span>, we finally get a system on 1st order ODEs:

<div class="math">$$
&#92;begin{align*}
&&#92;Phi&#95;{1}&#92;left( u&#95;{1},u&#95;{2} &#92;right) u&#95;{1}'&#92;left( x&#95;{1} &#92;right)  - &#92;Phi&#95;{2}&#92;left( u&#95;{1},u&#95;{2} &#92;right) u&#95;{2}'&#92;left( M-x&#95;{1} &#92;right) =0 &#92;&#92;
&&#92;Phi&#95;{1}&#92;left( u&#95;{1},u&#95;{2} &#92;right) u&#95;{1}'&#92;left( M- x&#95;{2} &#92;right)  - &#92;Phi&#95;{2}&#92;left( u&#95;{1},u&#95;{2} &#92;right) u&#95;{2}'&#92;left( x&#95;{2} &#92;right) =0 
&#92;end{align*}
$$</div>

Given initial condition <span class="math">$u&#95;{i}&#92;left( 0 &#92;right)=0$</span>, <span class="math">$&#92;forall i =1,2$</span>, both <span class="math">$u&#95;{1}$</span> and <span class="math">$u&#95;{2}$</span> are solvable from the above system:

<div class="math">$$
&#92;begin{align}
v&#95;{1}=u&#95;{1}&#92;left( x&#95;{1};M &#92;right) && v&#95;{2}=u&#95;{2}&#92;left( x&#95;{2};M &#92;right)
&#92;end{align}
$$</div>

Evaluate utilities at the corner point:

<div class="math">$$
&#92;Phi&#92;left( u&#95;{1}&#92;left( x&#95;{1}=M;M &#92;right),u&#95;{2}&#92;left( x&#95;{2}=0;M &#92;right) &#92;right)=0
$$</div>

We could finally pin down <span class="math">$M$</span>.

Therefore, there is a pair <span class="math">$&#92;left( u&#95;{1},u&#95;{2},M &#92;right)$</span> such that the image of this economy is the feasible set <span class="math">$con.comp&#92;left( S &#92;right)$</span> with the origin as its disagreement point. 


# There is not always a pair <span class="math">$&#92;left( u&#95;{1}, u&#95;{2} &#92;right): &#92;mathbb{R}&#95;{+}&#92;to &#92;mathbb{R}&#95;{+}$</span> and <span class="math">$M, M'&#92;in &#92;mathbb{R}&#95;{+}$</span> such that the image of the feasible set of the economy <span class="math">$&#92;left( u&#95;{1}, u&#95;{2}, M &#92;right)$</span> is <span class="math">$S$</span> and the image of the feasible set of <span class="math">$&#92;left( u&#95;{1}, u&#95;{2}, M' &#92;right)$</span> is <span class="math">$S'$</span>.


Here is a counterexample.

```latex
\begin{tikzpicture}[scale=2]
% Axes
\draw[->] (0,0) -- (2.2,0) node[right] {$u_1$};
\draw[->] (0,0) -- (0,1.2) node[above] {$u_2$};

% S region
\draw[thick] (0,0) -- (1,1);

% S' region
\draw[thick] (0,0) -- (2,0.5);

% L segment (dotted box)
\draw[dotted] (0.7,0.7) -- (0.7,1) -- (1,1) -- (1,0.7) -- cycle;

% L curve (wiggly)
\draw[thick] (0,1) .. controls (0.2,0.95) and (0.5,0.8) .. (0.7,0.7);

% Labels
\node at (1.5,0.3) {$S'$};
\node at (0.5,0.5) {$S$};
\node at (0.8,1.05) {$L$};
\end{tikzpicture}
```

Let <span class="math">$S :=&#92;left&#92;{ &#92;left( v&#95;{1},v&#95;{2} &#92;right) &#92;in &#92;mathbb{R}&#95;{+}^{2} &#92;text{ : } v&#95;{1}+v&#95;{2}&#92;leq 1 &#92;right&#92;}$</span> and <span class="math">$S :=&#92;left&#92;{ &#92;left( v&#95;{1},v&#95;{2} &#92;right) &#92;in &#92;mathbb{R}&#95;{+}^{2} &#92;text{ : } v&#95;{1}+2v&#95;{2}&#92;leq 2 &#92;right&#92;}$</span>.

By the way of contradiction, suppose there is a pair <span class="math">$&#92;left( u&#95;{1},u&#95;{2},M,M' &#92;right)$</span>, such that

<div class="math">$$
&#92;begin{align}
 & B&#95;{M}:=&#92;left&#92;{ &#92;left( u&#95;{1}&#92;left( x&#95;{1} &#92;right),u&#95;{2}&#92;left( x&#95;{2} &#92;right) &#92;right) &#92;text{ : }x&#95;{1}+x&#95;{2}=M &#92;right&#92;}=S & B&#95;{M'}:=&#92;left&#92;{ &#92;left( u&#95;{1}&#92;left( x&#95;{1} &#92;right),u&#95;{2}&#92;left( x&#95;{2} &#92;right) &#92;right) &#92;text{ : }x&#95;{1}+x&#95;{2}=M' &#92;right&#92;}=S'
&#92;end{align}
$$</div>

From <span class="math">$B&#95;{M}=S$</span>, we have

<div class="math">$$
&#92;begin{align}
 & &#92;frac{du&#95;{2}}{du&#95;{1}} = -&#92;frac{&#92;frac{du&#95;{2}}{dx&#95;{2}}}{&#92;frac{du&#95;{1}}{dx&#95;{1}}}=-1 &#92;&#92;
 &#92;implies & u&#95;{1}'&#92;left( x&#95;{1} &#92;right) = u&#95;{2}'&#92;left( x&#95;{2} &#92;right) = a &#92;geq0 &#92;text{ , } &#92;forall x&#95;{1},x&#95;{2} &#92;leq M
&#92;end{align}
$$</div>

Notice that all points <span class="math">$&#92;left( u&#95;{1}^{L},u&#95;{2}^{L} &#92;right)$</span> on the segment <span class="math">$L$</span> represents the amount of good assigned to each agent is less than <span class="math">$M$</span>, according to monotone of utilities:

<div class="math">$$
&#92;begin{align}
u&#95;{1}^{L}=u&#95;{1}&#92;left( x&#95;{1}^{L} &#92;right) &#92;leq u&#95;{1}&#92;left( M &#92;right)  & &#92;implies & x&#95;{1}^{L}&#92;leq M &#92;&#92;
u&#95;{2}^{L}=u&#95;{2}&#92;left( x&#95;{2}^{L} &#92;right) &#92;leq u&#95;{2}&#92;left( M &#92;right)  & &#92;implies & x&#95;{2}^{L}&#92;leq M &#92;&#92;
&#92;end{align}
$$</div>

Thus, along the segment <span class="math">$L$</span>, we have

<div class="math">$$
&#92;begin{align} &#92;&#92;
 & u&#95;{1}'&#92;left( x&#95;{1}^{L} &#92;right)=u&#95;{2}'&#92;left( x&#95;{2}^{L} &#92;right)=a &#92;&#92;
&#92;implies & &#92;frac{du&#95;{2}^{L}}{du&#95;{1}^{L}}=-&#92;frac{u&#95;{2}'&#92;left( x&#95;{2}^{L} &#92;right)}{u&#95;{1}'&#92;left( x&#95;{1}^{L}&#92;right)}=-1
&#92;end{align}
$$</div>

which is a contradiction to the slope of <span class="math">$S'$</span>: <span class="math">$&#92;frac{du&#95;{2}^{L}}{du&#95;{1}^{L}}=-&#92;frac{1}{2}$</span>. QED

The intuition here is the 2 subset should look "parallel" in the sense of same substitution ratio for the segment of <span class="math">$S'$</span> which is dominated by the aspiration of <span class="math">$S$</span> as well as that for segment of <span class="math">$S$</span>, i.e. the same slope on <span class="math">$L:=&#92;left&#92;{ u&#92;in  &#92;partial S' &#92;text{ : } u&#95;{i}&#92;leq a&#95;{i}&#92;left( S &#92;right), &#92;forall i &#92;in I:=&#92;left&#92;{ 1,2 &#92;right&#92;} &#92;right&#92;}$</span> and <span class="math">$&#92;partial S$</span>.

Although there might not always be a pair <span class="math">$&#92;left&#92;{ u&#95;{1},u&#95;{2},M,M' &#92;right&#92;}$</span> with <span class="math">$M,M'&#92;in &#92;mathbb{R}&#95;{+}$</span> to represent any 2 arbitrary convex and compact sets <span class="math">$S,S' &#92;subset &#92;mathbb{R}&#95;{+}^{2}$</span>, there could be a pair <span class="math">$&#92;left&#92;{ u&#95;{1},u&#95;{2},M,M' &#92;right&#92;}$</span> with <span class="math">$M,M'&#92;in &#92;mathbb{R}&#95;{+}^{L}$</span> to represent <span class="math">$S,S'$</span>, for <span class="math">$L&#92;geq 2$</span> (the number of good is no smaller than 2).
